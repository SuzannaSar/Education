# Исследование данных о российском кинопрокате

## Описание проекта
Проект выполнен по заказу **Министерства культуры Российской Федерации**.  
Цель исследования — изучить рынок российского кинопроката и выявить актуальные тренды.  
Отдельное внимание уделено фильмам, которые получили государственную поддержку, — мы анализируем, насколько такие фильмы интересны зрителю.  

## Данные
Использованы открытые данные Министерства культуры РФ:  
- информация о прокатных удостоверениях;  
- данные о сборах фильмов;  
- сведения о государственной поддержке;  
- дополнительные данные с сайта *КиноПоиск*.  

## Задачи исследования
- Изучить текущие тенденции на рынке российского кинопроката.  
- Сравнить популярность фильмов с господдержкой и без неё.  
- Определить, какие факторы влияют на интерес зрителей.
